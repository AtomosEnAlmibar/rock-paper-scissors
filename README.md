# rock-paper-scissors

- **Understand the problem**
We want a program that plays the game "Rock, paper, scissors", matching the computer against a user. The user will have to write the desired choice. The game will last 5 rounds, each round giving a point to the winner. The winner will be the one who has more points.
- **Plan**
	- This program will be console based, so it won't have an interface
	- The program will only receive a single input per round, that will be the text entered by the user.
	- The desired output will be who is declared winner. It will show up as a message in the console
	- The algorithm will have to compare the input of the user with the random choice of the computer, and declare who wins. Repeat that 5 times, and declare who the winner is.
